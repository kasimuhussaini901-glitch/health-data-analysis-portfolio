# Medical Laboratory Performance Dashboard

## Project Overview
Analyzed 500 synthetic laboratory tests to measure lab performance, turnaround time (TAT), and completion rate.

## Tools Used
- Google Sheets / Microsoft Excel
- Data Cleaning
- KPI Development
- Dashboard & Data Visualization

## Key Questions
1. What is the average Turnaround Time?
2. Which department has the highest workload?
3. What is the completion rate?

## Files in this Project
- lab_data.csv - Raw synthetic dataset (500 records)
- cleaned_data.csv - Cleaned dataset
- dashboard - Google Sheets Dashboard

## Disclaimer
All data is synthetic. No real patient information is used.
